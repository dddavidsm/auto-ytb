# Sourced Narrative

Sourced narrative is narration-led and evidence-first. The script is co-designed with media availability before it is locked.

1. Resolve entities and claims.
2. Discover exact and authoritative media.
3. Index assets at segment level.
4. Build availability and coverage reports.
5. Write narration around what can honestly be shown.
6. Assemble the master timeline from word/beat timing.
7. Run visual-narration, rights, technical and adversarial QC.

`DISCOVERY_REFERENCE` is research-only. `PUBLISHABLE_ASSET` requires a `RightsLedgerEntry`; finding a clip never implies permission to publish it. Exact entity coverage is preferred over generic B-roll, and a poor coverage row must be researched, rewritten or generated rather than hidden with effects.
