# Video DNA

`VIDEO_DNA_V1` stores observable structure, not copied expression: hook timing, central claim timing, narration density, shot rhythm, visual change rate, exact entity coverage, caption/audio signals and payoff timing.

Reference analysis compares outliers with category leaders and baseline videos. Public competitor retention is never fabricated. The output feeds a `VIDEO_BLUEPRINT_V1` as abstract guidance: promise, hook intent, information arc, media intents, predicted attention curve and packaging hypothesis.
