# AUTO-YTB V4

AUTO-YTB is a universal video production studio. Moss is only a stored test fixture; the production graph accepts sourced narrative, hybrid, one-off generation and persistent IP series.

## Operating modes

`LAB` runs experiments without publishing, `SHADOW` completes production without upload, `REVIEW` produces a human-review candidate, and `AUTOPILOT` is reserved for repeated human-calibrated quality evidence.

## Quality rule

The finished timeline is the product. Provider success, automated scores and rendered media are evidence only. A missing, rights-uncertain or semantically wrong asset blocks publication.

## Universal model

`ProductionBrief` is compiled into a `UniversalProductionGraph`. Profiles are scoped as `EPHEMERAL`, `PROJECT`, `SERIES`, `CHANNEL` or `GLOBAL`, so a one-off character and a recurring farm cast use the same architecture.

## Current priority

Sourced narrative is the primary vertical proof because exact real media can reach a useful quality floor sooner than unresolved multi-shot character continuity. Generative IP remains a secondary R&D lane with provider competency memory.
